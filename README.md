# PackIt — public pages

The privacy policy and support page for the PackIt iOS app, served by GitHub Pages
at <https://packit.bardsec.com>.

Separate from the app's own repository on purpose: GitHub Pages needs a public
repository, and the app source isn't public.

- `/privacy` — required by App Store review
- `/support` — also required by App Store review

Plain HTML and one stylesheet. No build step.
